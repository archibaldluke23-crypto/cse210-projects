Value types store data directly into their own memory space. (Unmaluable)
Reference types store a reference to the actual data. (Maluable)
This code assigns two references to the array:
int[] dataArray = new int[] {10, 20, 30};
int[] dataReference = dataArray;
dataReference[2] = 90;
When you display dataArray or dataReference they will now both read as {10, 20, 90}

ref is used to pass the actual variable instead of a copy of the variable to another function:
static void TestPassByReferenceUsingRef(ref int x)
        {
            x = 99;
            ...   
        }
        public static void Main(string[] args)
        {
          int x = 10;
          TestPassByReferenceUsingRef(ref x);
          Console.WriteLine(x);
          ...
        }
This will display 99 instead of 10

out is almost the same as ref but you don't have to set x equal to anything in the main function:
static void TestPassByReferenceUsingOut(out int x)
        {
            x = 199;
            ...   
        }
        public static void Main(string[] args)
        {
          int x;
          TestPassByReferenceUsingRef(out x);
          Console.WriteLine(x);
          ...
        }

To handle exceptions:
try
{
    // Attempt to divide by zero
    int numerator = 10;
    int denominator = 0;
    int result = numerator / denominator;
    Console.WriteLine("Result: " + result);
}
catch (DivideByZeroException ex)  //Handle only divide by 0 exception
{
    Console.WriteLine("Error: Cannot divide by zero.");
    Console.WriteLine("Exception message: " + ex.Message);
}
catch (Exception ex)  // Catches all other exceptions
{
    Console.WriteLine("Error: Exception Occurred");
    Console.WriteLine("Exception message: " + ex.Message);
}
finally
{
    Console.WriteLine("This block always executes, regardless of exceptions.");
}

This is the recipe.
public class Person
    {
        // The C# convention is to start member variables with an underscore _
        public string _givenName = "";
        public string _familyName = "";

        // A special method, called a constructor that is invoked using the  
        // new keyword followed by the class name and parentheses.
        public Person()
        {
        }

        // A method that displays the person's full name as used in eastern 
        // countries or <family name, given name>.
        public void ShowEasternName()
        {
            Console.WriteLine($"{_familyName}, {_givenName}");
        }

        // A method that displays the person's full name as used in western 
        // countries or <given name family name>.
        public void ShowWesternName()
        {
            Console.WriteLine($"{_givenName} {_familyName}");
        }
    }

Polymorphism: The ability to take on many forms. 
            One line of code can have different behavior depending on the context.

We can change methods from a child class by using method overriding:
public virtual float CalculatePay() // parent class
  {
    return salary;
  }
public override float CalculatePay() // child class
  {
    return rate * hours; // pay is calculated differently
  }

employees.add(new Employee());
employees.add(new HourlyEmployee());

// Get a custom calculation for each one
foreach(Employee employee in employees)
{
  float pay = employee.CalculatePay(); // this line is an example of Polymorphism because 
                                        // it calls the Employee calculate function and the 
                                        // HourlyEmployee calculate function
  Console.WriteLine(pay);
}

If your parent class doesn't need a function but at least 2 of its children do or the function 
needs to be slightly different for every class, then you can use abstraction:
public abstract class Employee // abstract parent
{
  // Notice the abstract method doesn't have a body at all (not even an empty one)
  // and it is followed by a semicolon.
  public abstract float CalculatePay();
}
public class SalaryEmployee : Employee // child
{
  private float salary = 100f;

  public override float CalculatePay()
  {
    return salary;
  }
}
public class HourlyEmployee : Employee // child
{
  private float rate = 9f;
  private float hours = 100f;

  public override float CalculatePay()
  {
    return rate * hours; // pay is calculated differently
  }
}

If a parent is abstract, you can no longer create an object 
of that parent class.
